# 🛡️ Fraud Guard: AI-based Scam Detection System

An intelligent system designed to identify and analyze potential scams in multiple formats using Machine Learning.

## 🌟 Project Overview
This project detects whether a message or image is a scam or safe, providing a **Scam Probability Score (Percentage)**.
- **Text Analysis**: Processing messages to identify fraudulent intent.
- **Image Analysis**: Scanning images for scam-related visual cues.
- **Current Focus**: Implementing robust **Classification and Regression** models.

## 🚀 Future Roadmap (In Progress)
I am actively enhancing this project with the following features:
*   **Voice Message Analysis**: Integrating **Speech-to-Text** to detect scam patterns in audio notes.
*   **Web & Mobile Application**: Building a user interface for real-time testing and accessibility.
*   **Multimodal Engine**: A unified system to process Text, Image, and Voice simultaneously.
